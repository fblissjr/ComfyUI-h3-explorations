### Added

- A preview of the song node writes what a render of the same graph will be given, with nothing sampled. With a source wired, `preview` now writes into `<prefix>_windows/`: `<name>_window_N_planned_region.npz` for each planned window, which is the file a render saves as its `_region.npz` (0.262.0), made by the render's own calls (`video_mask.window`, `source_margins`, `save_window_region`): the fitted mask, the token region per latent step with `keep`, `others`, the margin and the edge in, the trim, the composite's settings and the cuts; and `<name>_plan.json`: each window's first frame, length, latent steps, trim, the frames it writes, the share of its tokens that regenerate, the source frames held past the source's end, the latent steps a cut of the source splits (`loop_plan.split_steps`) and the frames the composite will leave as the source (`video_mask.cut_gate` on the planned mask), with the filled text of each window (`audio_freeze_song.write_plan`, `loop_resume.planned_region_path`, `plan_path`). Frame numbers are the load's. The files have their own names: no node reads them, a preview replaces them and removes an earlier plan's it has no window for, and a render leaves them alone and writes its own beside them, so a plan and the render made from it can be compared cell for cell. A window that starts past the source's end is not planned and the report says a render refuses the run.

### Changed

- A preview asks for one lazy input where it asked for none: the source, when it is wired (`PREVIEW_ASKS`). No model and no model's loader is behind it. What it costs is whatever is wired into the Masked Source: nothing for masks loaded from files, a tracker pass for a tracker wired live, which a render of the same graph then takes from core's cache. The preview's report says what it wrote and that the source was built for it; the shortfall line now also shows in a preview, since the source is there to measure against. The tooltip and the node's description say so.

- `docs/wiki/window_context.md`, new: a ledger for what ties a window to the window before it. The mechanism read from core (a frozen row is conditioning inside the picture; the references' level is one scalar for value and label and the same for every reference, so it cannot be set per reference without a patch to core), every lever with its kind and status, what a weaker context costs at the seam, the held tail of a short load as the same mechanism after the new frames (a scope, not built), and each result as a dated line. `docs/wiki/masked_v2v.md` links to it and gains a paragraph on the two files the song node writes about a render, before and after.
