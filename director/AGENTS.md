# Interactive Spatial Director (`director/`)

Standalone desktop web application backend, ComfyUI route extension, runtime workflow compiler, and launcher for interactive `[F, H, W]` spatial editing, D-Pad cutouts, and 3-frame audio cues on MiniMax H3 / Pika H3 Flex.

## Documentation & Direction

- **Enduring Product Vision (`5`-year compass):** [`director/VISION.md`](VISION.md) — timeless purpose, 7 core principles, 5-rule tradeoff compass, explicit non-goals, and long-term horizon.
- **Gap Analysis & 3-Horizon Roadmap:** [`director/ROADMAP.md`](ROADMAP.md) — code-verified gaps (`path::Symbol` & `path:line`) between current state and [`director/VISION.md`](VISION.md), ordered across Horizons 1–3.
- **User Guide & Progressive 6-Level Tutorial:** [`docs/wiki/spatial_director_guide.md`](../docs/wiki/spatial_director_guide.md) — mental model, current capabilities vs. hard limits, gestures/hotkeys, and step-by-step walkthrough (default landing page of `GET /docs`).

## Scope & Ownership

- `__init__.py` exposes [`_register_director_routes`](../__init__.py) to register `POST /h3_spatial_director/forget` on ComfyUI's server without patching ComfyUI core.
- `director/routes.py` implements `compute_forget_plan`, `delete_temp_files`, `forget`, and `register` with lazy runtime imports (`aiohttp`, `folder_paths`, `server`), cleaning temp `"images"`, `"audio"`, and `"gifs"` plus orphaned `h3_spatial_director/` uploads while never touching `$H3_OUTPUT_DIR/Video/` (`workflows/h3_config.py::output_dir`).
- [`director/compiler.py`](compiler.py) compiles still anchors (`compile_still`, defaulting to `"h3_image"` [`MiniMax-H3-Image`](../workflows/image/h3_image_t2i_api.json) alongside [`Pika H3 Image`](../workflows/image/h3_pika_image_t2i_api.json) and [`P-H3-Image`](../workflows/image/h3_p_h3_image_t2i_api.json), with `4.0 MP` floor and `for_cutout` studio isolation), 1-frame masked still pre-viz (`compile_masked_still_edit` with `MiniMaxH3EditGuider.mask` + `ModelPreviewOverrideKJ` `taeh3_image.safetensors` across [`h3_image_edit_api.json`](../workflows/image/h3_image_edit_api.json), [`h3_pika_image_edit_api.json`](../workflows/image/h3_pika_image_edit_api.json), and [`h3_p_h3_image_edit_api.json`](../workflows/image/h3_p_h3_image_edit_api.json)), SAM 3.1 segmentation (`compile_sam3_segment` with `MiniMaxH3SAM31Corrections` -> `SAM3_Detect`), and scene-agnostic spatial video takes (`compile_spatial_take`: `i2v_portal` Frame-0 default without sprite cutout, `r2v_portal` when a movable sprite cutout is attached, `t2v_portal`, `world_targets`, including `combined` director mode, `first_frame` + `last_frame`, optional 2nd-pass `MiniMaxH3FrozenVideoCache` + `MiniMaxH3AudioRefineMask`), plus standalone video-frozen audio re-dub (`compile_audio_redub`). It synthesizes matched `<Picture 1>`-anchored `original`/`edited` H3 prompts (`synthesize_spatial_prompts`, `synthesize_image_edit_prompts`) with zero shipped-benchmark fallback text, enforces `h3_rules.py::on_both_clocks`, computes `99,864`-token preflight, scales plans (`escalate_plan`), and injects `ModelPreviewOverrideKJ` (`"165"`) with `video_preview_schedule` (`MAX_VIDEO_PREVIEW_FRAMES = 27` at 1.0x `preview_fps`) when exposed by `/object_info`.
- [`director/server.py`](server.py) serves the Light-Mode CSP World Sandbox web UI (`/` and `/static/`, including modular [`director/static/js/stage.js`](static/js/stage.js), [`director/static/js/sequencer.js`](static/js/sequencer.js), [`director/static/js/ab_compare.js`](static/js/ab_compare.js), [`director/static/js/foley_synth.js`](static/js/foley_synth.js), [`director/static/js/ws_client.js`](static/js/ws_client.js) persisting `clientId` in `sessionStorage`, and [`director/static/js/app.js`](static/js/app.js) re-hydrating in-flight renders from `/api/takes` `active_prompt_ids` with live `step_ms`/`Δ` telemetry), the single-place Markdown Documentation & Tutorial Hub (`GET /docs` backed by [`director/static/docs.html`](static/docs.html), [`director/static/docs.css`](static/docs.css), [`director/static/js/docs_viewer.js`](static/js/docs_viewer.js), and live `/api/docs` + `/api/docs/file` + `/api/docs/asset`), validates `Host`/`Origin`/`Sec-Fetch-Site` and `HttpOnly; SameSite=Strict` session cookies, stores session state under `--state-dir`, exposes all `/api/*` endpoints (including HTTP `Range`-capable `/api/view`, per-`clientId` `/api/ws`, `POST /api/preview_in_mask`, `POST /api/stamp_cutout`, `POST /api/segment`, `POST /api/extract_frame`, `POST /api/redub`, `heylook` `POST /v1/messages` in `POST /api/context_suggest`, and MP4 import in `POST /api/upload`), and exports approved temp MP4s into `$H3_OUTPUT_DIR/Video/`.
- An optional local launcher (when symlinked at `director/studio.sh`) manages start/stop/status/url/logs via `h3.env` / CLI port configuration without touching ComfyUI `:8188`.

## Rules

1. Never use bare filenames in prose/citations; keep all paths repo-relative (no absolute user-home, mount paths, or owner names).
2. Draft takes write only to `temp/` (`"save_output": false` on `"13"` HUD and `"162"` clean `VHS_VideoCombine`, plus `PreviewImage` on anchor stills). Only explicit `POST /api/export` promotes an MP4 into `$H3_OUTPUT_DIR/Video/`.
3. Keep `director/routes.py` and `director/compiler.py` top-level imports strictly stdlib so `bench/check_imports.py` passes offline.
4. Keep spatial take lengths on `h3_rules.py::on_both_clocks` (`39, 90, 141, 192, 243, 294, 345`) and sound cues snapped to 3-frame (`125 ms`) boundaries.
5. `POST /api/context_suggest` returns `{ok: true, enabled: false, suggestions: []}` unless `H3_HEYLOOK_URL` is configured and reachable.
