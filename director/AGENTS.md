# Interactive Spatial Director (`director/`)

Standalone desktop web application backend, ComfyUI route extension, runtime workflow compiler, and launcher for interactive `[F, H, W]` spatial editing, D-Pad cutouts, and 3-frame audio cues on MiniMax H3 / Pika H3 Flex.

## Documentation & Direction

- **Enduring Product Vision (`5`-year compass):** [`director/VISION.md`](VISION.md) — timeless purpose, 7 core principles, 5-rule tradeoff compass, explicit non-goals, and long-term horizon.
- **Gap Analysis & 3-Horizon Roadmap:** [`director/ROADMAP.md`](ROADMAP.md) — code-verified gaps (`path::Symbol` & `path:line`) between current state and [`director/VISION.md`](VISION.md), ordered across Horizons 1–3.
- **User Guide & Progressive 6-Level Tutorial:** [`docs/wiki/spatial_director_guide.md`](../docs/wiki/spatial_director_guide.md) — mental model, current capabilities vs. hard limits, gestures/hotkeys, and step-by-step walkthrough (default landing page of `GET /docs`).

## Scope & Ownership

- `__init__.py` exposes [`_register_director_routes`](../__init__.py) to register `POST /h3_spatial_director/forget` on ComfyUI's server without patching ComfyUI core.
- `director/routes.py` implements `compute_forget_plan`, `delete_temp_files`, `forget`, and `register` with lazy runtime imports (`aiohttp`, `folder_paths`, `server`), cleaning temp `"images"`, `"audio"`, and `"gifs"` plus orphaned `h3_spatial_director/` uploads while never touching `$H3_OUTPUT_DIR/Video/` (`workflows/h3_config.py::output_dir`).
- [`director/compiler.py`](compiler.py) and [`director/graph_builder.py`](graph_builder.py) compile still anchors (`compile_still`, defaulting to `"h3_image"` [`MiniMax-H3-Image`](../workflows/image/h3_image_t2i_api.json) alongside [`Pika H3 Image`](../workflows/image/h3_pika_image_t2i_api.json) and [`P-H3-Image`](../workflows/image/h3_p_h3_image_t2i_api.json)), 1-frame masked still pre-viz (`compile_masked_still_edit` with `"auto"` warm-resident workflow resolution via `resolve_image_edit_workflow`, `MiniMaxH3EditGuider.mask` + `ModelPreviewOverrideKJ` `taeh3_image.safetensors`), SAM 3.1 segmentation (`compile_sam3_segment`), and scene-agnostic spatial video takes (`compile_spatial_take`: `i2v_portal` Frame-0 default at `141f`, `r2v_portal` / `world_targets` pinning Frame 0 via `"169"` `MiniMaxH3GuideLatent` and optional `include_sprite_envelope` D-pad mask union on `"160"`, `t2v_portal`, plus `finalize_lean_baseline` single-pass `[original]` baseline builder and `wire_audio_refine_pass`), as well as standalone video-frozen audio re-dub (`compile_audio_redub`, including `isolate_visuals=True` (`7a7693d0`) wiring uncached `MiniMaxH3AudioRefineMask` + `MiniMaxH3QueryRouter(audio_conditioning=["26", 0], aud_to_vid_gain=0.0)`). They synthesize chronological `<T.T seconds>` `<Picture 1>`-anchored prompts (`_collect_spatial_beats`, `_dpad_motion_summary`, `synthesize_spatial_prompts`), enforce `h3_rules.py::on_both_clocks`, compute `99,864`-token preflight, scale timelines (`escalate_plan`), and inject `ModelPreviewOverrideKJ` (`"165"`).
- [`director/server.py`](server.py), [`director/store.py`](store.py), and [`director/media.py`](media.py) serve the Light-Mode CSP World Sandbox web UI (`/` and `/static/`, including modular [`director/static/js/stage.js`](static/js/stage.js) with non-overlapping pill placement and explicit couplings, [`director/static/js/sequencer.js`](static/js/sequencer.js), [`director/static/js/ab_compare.js`](static/js/ab_compare.js), [`director/static/js/foley_synth.js`](static/js/foley_synth.js) with stereo `StereoPannerNode`, [`director/static/js/takes_ui.js`](static/js/takes_ui.js), [`director/static/js/ws_client.js`](static/js/ws_client.js), and [`director/static/js/app.js`](static/js/app.js)), plus the Markdown Hub (`GET /docs`), validate `Host`/`Origin`/`Sec-Fetch-Site` and `HttpOnly; SameSite=Strict` cookies, extract clean-plate/SAM RGBA cutouts (`extract_studio_cutout_rgba`, `encode_rgba_cutout_png`), compute `invert_mask` + `sprite_envelope`-aware A|B localization metrics (`compute_ab_metrics_sync`), prepare reticle+ROI local VLM payloads (`prepare_vlm_reticle_images`), persist Shot-DAG `SessionStore` history + `.director.json` sidecar recipes under `--state-dir`, and export approved temp MP4s into `$H3_OUTPUT_DIR/Video/`.
- An optional local launcher (when symlinked at `director/studio.sh`) manages start/stop/status/url/logs via `h3.env` / CLI port configuration without touching ComfyUI `:8188`.

## Rules

1. Never use bare filenames in prose/citations; keep all paths repo-relative (no absolute user-home, mount paths, or owner names).
2. Draft takes write only to `temp/` (`"save_output": false` on `"13"` HUD and `"162"` clean `VHS_VideoCombine`, plus `PreviewImage` on anchor stills). Only explicit `POST /api/export` promotes an MP4 into `$H3_OUTPUT_DIR/Video/`.
3. Keep `director/routes.py`, `director/compiler.py`, `director/graph_builder.py`, `director/store.py`, and `director/media.py` top-level imports strictly stdlib so `bench/check_imports.py` passes offline.
4. Keep spatial take lengths on `h3_rules.py::on_both_clocks` (`39, 90, 141, 192, 243, 294, 345`) and sound cues snapped to 3-frame (`125 ms`) boundaries.
5. `POST /api/context_suggest` returns `{ok: true, enabled: false, suggestions: []}` unless `H3_HEYLOOK_URL` is configured and reachable.
