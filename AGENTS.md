## 1. Operative Rules

1. **Never run `uv` here** (`uv run`, `uv sync`, `uv add`): with ComfyUI's `.venv` active, `uv` has emptied `.venv` and dirtied `uv.lock`. Run scripts with ComfyUI's venv Python directly:
   ```bash
   COMFY="$(cd ../.. && pwd)" && "$COMFY/.venv/bin/python" <script.py>
   ```
   In `agy`, each shell call spawns a fresh subshell: set `PY` and load `$H3_*` at the top with `set -a; . ./h3.env; set +a` ([`docs/wiki/ops/comfy_notes.md`](docs/wiki/ops/comfy_notes.md)). In standalone scripts, call `bench/_lib/__init__.py::bootstrap` before `import comfy` so root [`nodes.py`](nodes.py) never shadows ComfyUI's `nodes.py`.
2. **Path privacy (`bench/check_no_owner_paths.py`):** Use `$H3_INPUT_DIR`, `$H3_OUTPUT_DIR` (`$H3_OUTPUT_DIR/Video`), `$H3_MODEL_STORE`, and `$H3_CAPTURE_ROOT` from gitignored `h3.env` ([`h3.env.example`](h3.env.example)); never commit local mount paths, home paths, share names, or personal names. All tracked paths must be repo-relative. Note `:8188` resolves inputs/outputs via `--input-directory` / `--output-directory` in `<comfy>/start.sh`.
3. **Git & worktrees:** Check `git status` before editing, verify explicit pathspecs with [`bench/check_commit_ready.py`](bench/check_commit_ready.py), and commit promptly with `git commit -F <msg> -- <paths>` (`git add -- <new_file>` only for brand-new files). Never run bare `git add`, `git commit -a`, bare `git commit`, `--amend`, or `git push`. Leave a peer's uncommitted hunk for them to commit. Isolate worker checkouts at `../../h3_worktrees/<branch>` (never inside `custom_nodes/`). Normal commits do not touch `CHANGELOG.md` ([`changelog.d/README.md`](changelog.d/README.md)).
4. **Never patch ComfyUI core; never hand-edit generated files:** API workflows (`workflows/**/*.json`) are generated by [`workflows/build_workflows.py`](workflows/build_workflows.py) + [`workflows/h3_config.py`](workflows/h3_config.py); `INDEX.md` files (`INDEX.md`, `bench/INDEX.md`, `bench/results/INDEX.md`, `workflows/INDEX.md`, `docs/wiki/image/workflows_matrix.md`) by [`bench/build_index.py`](bench/build_index.py); `docs/wiki/prompting/prompt_bank.md` by `bench/build_prompt_bank.py`. Keep `vendor_config/` and `vendor_guides/` verbatim, `vendor/` licenses intact, and `archive/` read-only history.
5. **Node schema & widget stability ([`bench/check_node_ids.py`](bench/check_node_ids.py), [`bench/check_literal_widgets.py`](bench/check_literal_widgets.py)):** Never rename a `node_id=` or insert/reorder a node's `inputs`/`outputs` anywhere except the **end**, and never use `0` as a mode sentinel on numeric widgets. (`H3ExplorationsExtension.get_node_list()` in [`nodes.py`](nodes.py) is dict-keyed by `node_id` in ComfyUI core and may be grouped cleanly.)
6. **Check `:8188` before restarting ComfyUI:** Inspect `ss -ltnp 'sport = :8188'` and `tr '\0' '\n' < /proc/$PID/environ | grep '^H3_'` before stopping `:8188`; an `H3_*` key means an active capture is armed — ask first.
7. **Media inspection (`agy`):** Follow [`.gemini/skills/video-understanding/SKILL.md`](.gemini/skills/video-understanding/SKILL.md) — inspect `.1fps.<first>-<last>.mp4` companions, `< 100 MB` `.mp4`, and `.png`/`.jpg` stills with native `read_file` first before using Gemini media helpers.

## 2. Peer Collaboration Norms

- **Clock & timestamps:** Collaborators operate in US Central for relative time references; read timestamps from the system clock or file rather than estimating.
- **No media in `data/`:** Videos, `.1fps` review strips, PNGs/JPGs, crops, and comparison grids go under `$H3_OUTPUT_DIR`; `data/` keeps only scripts, JSON, logs, and prompts.
- **No external uploads without asking:** Never upload local renders, clips, stills, or audio to an external/hosted API without asking first and naming what leaves the machine.
- **Comparative, observable judging:** Evaluate renders side-by-side at matched seeds in plain English with file names and frame numbers (no invented numeric scores); verify code/data claims directly on disk before agreeing.
- **Read full queued prompts when debugging:** Scaling pre-render checks with stakes is fine, but any prompt read or debugged for a failed render must be read whole as queued (`bench/what_h3_got.py`), never from a paraphrase.
- **Keep it simple:** Simplest fix first, zero bookkeeping inputs on nodes, state a recommendation + one-line why on open decisions, and remove rules that add friction without preventing real bugs.

## 3. H3 Frame, Clock, Mask & Canvas Cheat Sheet

Details live in [`docs/wiki/core/h3_frame_rules.md`](docs/wiki/core/h3_frame_rules.md), [`h3_rules.py`](h3_rules.py), and [`docs/wiki/core/h3_resolutions.md`](docs/wiki/core/h3_resolutions.md):

- **Fixed clocks (`FRAME_RESCALE = 5/3`):** `24 fps` video and `40 Hz` (`25 ms`, `32 kHz / 800` hop) audio; always resample inputs to `24.0 fps`.
- **Video VAE `17n + 5` (`5..362`) -> `5n + 2` latent steps:** Causal `[1, 4, 4, 4, 4]` clips (`frames 0, 17, 34, ...` are `1`-frame standalone clip starts; steps `1..4` pack `4` frames across `32x32` px DiT patches). Masks/inpaint operate per `(latent_step, 32x32)` token.
- **Dual-clock grid `39 + 51m` (`39, 90, 141, 192, 243, 294, 345`):** Required for all chained loops, `audio_freeze_song`, and `masked_v2v` (`LONG_WINDOW = 345`; off-grid `17n + 5` up to `362` only for standalone single windows).
- **Never wire stock `SetLatentNoiseMask` onto H3 AV latents:** It flattens `NestedTensor(video, audio)`, corrupting audio and causal chunks; use [`MiniMaxH3MaskedSource`](video_mask.py) or [`MiniMaxH3FreezeAudio`](audio_freeze.py).
- **Keyframes, `3f` sound cues & `<Video N>` refs:** `MiniMaxH3GuideLatent` pins `t >= 0`; `MiniMaxH3SoundCues` snaps cues to `3`-frame (`125 ms`) steps; `<Video N>`/`<Picture N>` refs sit at `t < 0` (`2 fps` Qwen view); `MiniMaxH3ReleaseReferences` (`0.33` on 6-step Pika) releases scaffolding mid-denoise.
- **Video vs single-frame (`t = 1`) image contract:** AV video uses `768` short edge / `1344x768` (`7:4`) cap, `shift=12.0/3.0`, structured sections, and `int64`-safe attention past **`99,864` packed tokens** (`MiniMaxH3Sol`, `MiniMaxH3SageAttention`, or kitchen). [`MiniMax-H3-Image`](docs/wiki/image/h3_image.md) (unpacked 5D, `16 -> 4 MP`, `PH3_IMAGE_VAE`, `shift=1.0`, sectionless prompts) and [`P-H3-Image`](docs/wiki/image/p_h3_image.md) (`NestedTensor`, `[4..8] -> 4 MP`, `shift=1.0`) use separate contracts.
