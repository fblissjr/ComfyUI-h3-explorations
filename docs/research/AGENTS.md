# docs/research/: dated studies and postmortems

Loaded when a session opens a file here; `docs/AGENTS.md` and the root `AGENTS.md` still govern.

- **A record here is what was true when it was written**, not current guidance. The current answer is on a topic page
  (`docs/index.md` routes to it); a study that changes it is linked from that page.
- **`index.md` lists every record here**, and a subfolder with a README (`pdd/`) orders its own.
- **A record is not rewritten after the fact.** A later finding goes in as a dated annotation, or a new record.
