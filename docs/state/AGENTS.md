# docs/state/: where things stand

Loaded when a session opens a file here; `docs/AGENTS.md` and the root `AGENTS.md` still govern.

- **`index.md` lists every page here.** Read it first; a new page gets a row.
- **`handover.md` is the day boundary**: rewritten each evening, about 80 lines, four headings (root `AGENTS.md`,
  "Where state lives"). It replaces yesterday's; it does not accumulate.
- **`next_steps.md` is pointers, not reasoning.** A done item leaves it; the why lives in the page or record it points
  at. When it and `roadmap.md` disagree, the roadmap is right.
- **`decisions.md` is the only log**: one dated line per decision or corrected claim, newest first, with what it used to
  say. Pages elsewhere carry the current answer, not their own history.
