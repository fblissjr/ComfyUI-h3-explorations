# Open experiments

What has not been measured, what each run would settle, and what blocks it. An experiment belongs here only if its
result would change a decision (a default, a doc claim, a piece of code); curiosity is cut, not parked. Entry numbers
are stable because other files cite "#N"; a closed entry keeps one line in "Closed entries" below. The full text of
every entry as it stood before the 2026-10-19 sweep is in git at `901bee1`, `docs/state/open_experiments.md`.
[`../method/checks.md`](../method/checks.md) is the companion index of what *is* checked.

Last swept: 2026-10-19 (closed and settled entries moved to the table; open entries cut to question, blocker, link).
