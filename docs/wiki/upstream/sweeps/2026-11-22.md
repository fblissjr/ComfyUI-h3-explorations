- **P-H3-Image became P-Image-OSS on Hugging Face** (2026-11-19). The renamed `p-image-oss_*` files are
  byte-identical to the old ones by LFS hash, and the old names are still served; the card's defaults did not

  `h3_config.PH3_IMAGE_UPSAMPLER`'s file name.
- **On the owner's Pika:** ReDiverse (`kabachuha/ReDiverse-Pika-H3-Flex-Comfy`, a Comfy port of a gated
  `ReDiverse/ReDiverse-Pika-H3-Flex`; paper arXiv 2611.18550) restores seed diversity after distillation with an
  adapter run on the first step only, plus a training-free mode that steers activations along the teacher's

  LoRA fits `MiniMaxH3LoRABranch`'s step window (`lora_branch.py`, `_Window`); the training-free mode is in the

  pruned AdaLN curve misses the official bf16 modulation by a few bf16 ulps on a large share of values, and
  replaces the curve with a seven-row one-hot table (the six sigmas and the reference level) that core's curve
  loader takes unchanged. Its timesteps are `1 -` `H3_IMAGE_MANUAL_SIGMAS` (aligns). NVFP4 is Blackwell-only; the
  table is separable from it. The claim was measured on its files, not on the owner's int8 file. DiffSynth's
  `MiniMax-H3-Image-EntroPack` is a six-step table of the same kind, called lossless by its card (read).

  (an empty-picture push on the first steps and a re-noise sampler), `igorls/comfyui-h3-sampler` (frequency-split
  re-noise, an empty-picture node), WanGP #2663 (LCM and `euler_ancestral` reported less noisy than Euler at 16
  MP), a style LoRA run on LCM. All differ from the engines, which use velocity Euler and give text to image no
  vision tokens ([`../topics/h3_image_sampling_step.md`](../topics/h3_image_sampling_step.md)). Multi-step
