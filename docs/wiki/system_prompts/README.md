## MiniMax-H3-Image prompts (`h3_image/` vs. `vendor_guides/h3_image/`)

[`h3_image/`](h3_image/README.md) holds six standalone English-only system prompts for local thinking LLMs/VLMs (`t2i_*`, `t2i_design_*`, and `edit_*`, each in plain-caption and trailing `aspect_ratio:` variants), preserving the exact caption structure the DiT expects without constrained JSON decoding, multilingual/benchmark fluff, or synthetic API pre-parts.

MiniMax's untouched vendor middleware prompts and worked examples remain hash-pinned in [`vendor_guides/h3_image/`](../../../vendor_guides/h3_image/) (see [`vendor_guides/h3_image/README.md`](../../../vendor_guides/h3_image/README.md) for how MiniMax's hosted expander formats `.format(request)` JSON-schema T2I calls and multi-part `Reference Media` Edit calls). [`h3_image_nodes.py::parse_expander_reply`](../../../h3_image_nodes.py) parses plain captions, trailing `aspect_ratio:` lines, and vendor `expanded_caption` JSON replies alike, handing any parsed ratio to `resolve_size` (`workflows/h3_config.py::h3_image_size`; in a graph, `MiniMax H3 Image Size`). [`docs/h3_image.md`](../../h3_image.md) documents the model and its workflows.
