# H3 System Prompts (`docs/wiki/system_prompts/`)

Canonical system prompts for generating single-frame image generation and 1–8 reference image editing prompts ([`h3_p_h3_image_system_prompt.md`](h3_p_h3_image_system_prompt.md)), multi-frame video+audio scene prompts ([`h3_system_prompt.md`](h3_system_prompt.md)), and activation control-vector contrastive pair sets ([`h3_control_vector_system_prompt.md`](h3_control_vector_system_prompt.md)).

| System Prompt | Purpose | Verified By |
|---|---|---|
| [`h3_p_h3_image_system_prompt.md`](h3_p_h3_image_system_prompt.md) | Three self-contained, copy-pasteable fenced system prompts (zero model lore, zero subject-biasing examples) for single-frame image generation and editing: **§1 Text-to-Image** (`120–250` words in `1–2` paragraphs), **§2 Image Edit — Direct Single-Paragraph** (`Edit <Picture 1>. ... Keep ... unchanged.`), and **§3 Image Edit — Structured 6-Section Brief** (`[keyframe completion]`) | [`bench/check_prompt_docs_sync.py`](../../../bench/check_prompt_docs_sync.py) (`PH3_*_RULE_PINS` + `PH3_FORBIDDEN_LORE`), [`bench/check_prompt_guide_conformance.py`](../../../bench/check_prompt_guide_conformance.py) |
| [`h3_system_prompt.md`](h3_system_prompt.md) | General H3 multimodal video+audio scene-prompt writer (`CORE` + `MODE` blocks for `t2va`, `i2va`, `fl2va`, `l2va`, `ref2va`) derived from [`docs/prompting.md`](../../prompting.md) and [`vendor_guides/`](../../../vendor_guides/) | [`bench/check_prompt_docs_sync.py`](../../../bench/check_prompt_docs_sync.py) (`RULE_PINS` + `BASE_ALIGNMENT`), [`bench/grade_prompt_text.py`](../../../bench/grade_prompt_text.py) |
| [`h3_control_vector_system_prompt.md`](h3_control_vector_system_prompt.md) | Canonical control-vector authoring system prompt (`### Test Scene Prompt` + stratified `### Contrastive Pairs (1–10)` + optional `### Hold Pairs`, coupled `description + overall_soundscape` diffs, and `--words` short-contrast compiler specs) plus reference tables for all authoring/synthesis variants, `rebuild`, J-Lens readiness/receptor diagnostics, Studio UI (`bench/control_vectors.py ui`), and ComfyUI nodes (see also [`docs/wiki/control_vectors/llm_prompting_guide.md`](../control_vectors/llm_prompting_guide.md) for copy-paste user input prompt examples) | [`bench/check_prompt_docs_sync.py`](../../../bench/check_prompt_docs_sync.py) (`BASE_ALIGNMENT` + `CV_RULE_PINS`), [`bench/check_control_vectors.py`](../../../bench/check_control_vectors.py) |
