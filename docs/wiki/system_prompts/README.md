## Syncing to `heylook` & `@extend` runtime overlays

- [`bench/sync_heylook_presets.py`](../../../bench/sync_heylook_presets.py) (`06c64f9f`, `d5173f0f`; verified by [`bench/check_sync_heylook_presets.py`](../../../bench/check_sync_heylook_presets.py)) idempotently synchronizes all `23` catalog prompts from `docs/wiki/system_prompts/` (including both fenced blocks inside `h3_p_h3_image_system_prompt.md`, `h3_director/`, and `h3_query_router/`) verbatim to `/v1/presets` with `--list`, `--dry-run` (default), `--diff`, `--apply`, `--only`, `--prefix`, and `--reset-params`, preserving remote sampler params unless `--reset-params` is passed. Synced presets are automatically inherited downstream across `auto_edit_prompt.py`, `h3_image_nodes.py`, and `director/server.py`.
- `@extend:prepend|append` (or `<!-- H3_EXTEND:prepend|append -->`) inside a preset or custom system prompt composes additively around the active local `.md` H3 contract via [`heylook_client.py::compose_preset_system_prompt`](../../../heylook_client.py) across `1x` Video (`auto_edit_prompt.py`), `1x` Image (`h3_image_nodes.py`), `2x` AutoEdit (`auto_edit_prompt.py`), and H3 Pocket Console (`app/heylook_bridge.py`).

## MiniMax-H3-Image prompts (`h3_image/` vs. `vendor_guides/h3_image/`)

[`h3_image/`](h3_image/README.md) holds six standalone English-only system prompts for local LLMs/VLMs (`t2i_*`, `t2i_design_*`, and `edit_*`, each in plain-caption and trailing `aspect_ratio:` variants), keeping natural `"double-quoted"` captions aligned with the DiT encoder without constrained JSON decoding, SFT `<Subject N>` compiler scaffolding, multilingual/benchmark fluff, or synthetic API pre-parts.

MiniMax's untouched vendor middleware prompts and worked examples remain hash-pinned in [`vendor_guides/h3_image/`](../../../vendor_guides/h3_image/) (see [`vendor_guides/h3_image/README.md`](../../../vendor_guides/h3_image/README.md) for how MiniMax's hosted expander formats `.format(request)` JSON-schema T2I calls and multi-part `Reference Media` Edit calls). [`h3_image_nodes.py::parse_expander_reply`](../../../h3_image_nodes.py) parses plain captions, trailing `aspect_ratio:` lines, and vendor `expanded_caption` JSON replies alike, handing any parsed ratio to `resolve_size` (`workflows/h3_config.py::h3_image_size`; in a graph, `MiniMax H3 Image Size`). [`docs/wiki/image/h3_image.md`](../image/h3_image.md) documents the model and its workflows.
