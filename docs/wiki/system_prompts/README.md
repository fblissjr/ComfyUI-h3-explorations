## The two MiniMax-H3-Image prompts

`h3_image_t2i_system_prompt.md` and `h3_image_edit_system_prompt.md` are the vendor's files, copied whole from the `prompt/` folder that came with the model. Nothing in them is ours and neither is to be edited; the release's other prompt files and its worked examples are in [`vendor_guides/h3_image/`](../../../vendor_guides/h3_image/).

How each is sent and how its reply is used is the vendor's to say, and they say it in the expander repository's README, kept whole at [`vendor_guides/h3_image/README.md`](../../../vendor_guides/h3_image/README.md) ("How to use T2I PE", "How to use Image editing PE"). In short:

- **Text to image.** The file is a Python format string that ends with `input_text: {}`: the user message is the file with the request put in by `.format(request)`, which also turns the doubled braces around its JSON examples into single ones. The vendor sends a one-paragraph system prompt in front of it (`vendor_guides/h3_image/prompt/t2i/system_prompt.txt`, which repeats the reply format) and fixed request settings (`prompt/t2i/request_params.json` there: thinking on, sampling at the model's defaults, and the reply held to a JSON schema whose `aspect_ratio` is one of ten ratios). The model it is written for is MiniMax's own expander, a fine-tuned language model served with the reply constrained to that schema.
- **Edit.** One user message and no system prompt: the file unchanged as the first part; a line giving the number of pictures; each picture preceded by a text part that names it (`<Picture 1>`, ...) and gives its own aspect ratio; and a last text part with the editing instruction as a JSON string and the aspect ratio wanted (a `W:H` ratio, or `adaptive`). The vendor's README has the exact wording of each part. MiniMax say this half is still under development and release the prompt only: it is for a vision-language model of your choosing.
- **Using the reply.** `expanded_caption` is the image model's prompt, as it is, with the same pictures in the same order for an edit. The ratio in the reply is used only when none was chosen beforehand: a ratio you picked yourself wins over the model's. A ratio becomes a size by the vendor's rule (`workflows/h3_config.py::h3_image_size`; in a graph, the `MiniMax H3 Image Size` node). [`docs/h3_image.md`](../../h3_image.md) is the page on the model and its workflows.
