🔬 The Core Math: What Tau (τ) Really Does

In standard dense attention, every single query attends to every single key, scaling quadratically: O(T²). For MiniMax H3's packed 100k+ token sequences (combining text, reference images, audio, and video), this requires billions of pairwise calculations.

Threshold:   Ti = μi + τ · σi

Sol-Attn (arXiv:2607.24027) turns this into an intelligent adaptive statistical filter:

1
64-Token Tiles
Keys and values are divided into chunks of 64 tokens. Each 64-token block is summarized by its average vector (the centroid).
2
Coarse Scoring
For query block i, coarse dot products are computed against every key centroid in fast INT8 arithmetic.
3
Calculate μ and σ
The kernel measures the mean (μ) and standard deviation (σ) of attention scores specifically for that query row.
4
Apply τ Cutoff
Key blocks scoring ≥ μ + τσ get full 64×64 exact attention. Unselected blocks are pooled into the centroid tail.
The Breakthrough Contribution: Unlike older sparse attention methods (which simply dropped unselected tokens to zero and caused severe softmax distortion), Sol-Attn keeps the pooled tail. The unselected blocks still contribute their proxy energy to the softmax denominator, preventing probability drift!
🖼️ Interaction With Reference Images

When you provide two reference images upscaled to 2048 short edge, they inject ~8,000 to ~15,000 latent rows into the packed sequence. Here is how τ interacts with them:

The Exact KV Sink Guarantee:
Under sink_conditioning = 'exact_kv_and_rows', all reference latent rows reside in the exact prefix. This means that no matter how high you set τ, every generated video query block attends to your reference image rows with 100% exact pairwise attention! Tau only sparsifies the video-to-video self-attention and reference-to-reference queries.

Summary of Practical Tau Settings:

  • τ = 0.5 - 0.8: High-density (~25-35% exact). Use if you notice subtle texture flicker or very fine facial details drifting over long videos.
  • τ = 1.0 (Recommended): Ideal balance (~16% exact). Matches the official NVLabs and SGLang production recipes. 1.7×–1.9× faster than dense attention with virtually zero perceptual difference.
  • τ = 1.3 - 1.5: Sparser (~7-10% exact). Noticeably faster for rapid iterations, but can slightly soften complex micro-motions.
  • τ > 2.0: Ultra-sparse (<3% exact). Only huge outlier features are attended exactly; can cause loss of coherence or blurry background textures.
