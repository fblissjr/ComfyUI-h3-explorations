## 2. Critical Architectural Catch: Why SAM 3.1 Is Already Free, While Phase 2B Hits `H3MaskedSource`

Inspecting the actual schema and consumer graph of [`video_mask.py`](../../../video_mask.py) and [`audio_freeze_song.py`](../../../audio_freeze_song.py) resolves both how to leverage SAM 3.1 today and a hidden wiring trap in [`image/2026-11-14_embedded_image_in_video_plan.md`](image/2026-11-14_embedded_image_in_video_plan.md) (**Phase 2B**):

1. **Perception (`MiniMaxH3SAM31Corrections` -> `MiniMaxH3SubjectTrack` -> `MiniMaxH3SubjectParts` / `MiniMaxH3SubjectBoxes`) has zero dependency on [`MiniMaxH3AudioFreezeSong`](../../../audio_freeze_song.py).**
   - Every node in [`workflows/masked_job_graph.py`](../../../workflows/masked_job_graph.py#L275-L356) (`preview(job)`) outputs standard ComfyUI types (`MASK`, `IMAGE`, `STRING` JSON) and runs with **no DiT and no song node**.
2. **`H3MaskedSource` is what actually locks masked v2v to `MiniMaxH3AudioFreezeSong`:**
   - [`H3MaskedSource`](../../../video_mask.py#L248) is a custom dict wrapper returned by [`MiniMaxH3MaskedSource`](../../../video_mask.py#L2330). Across the entire repository, its only consumers are [`audio_freeze_song.py:598`](../../../audio_freeze_song.py#L598) and optional prompt-text assembly in [`masked_prompt.py:89`](../../../masked_prompt.py#L89).
   - Meanwhile, the actual math inside [`video_mask.py`](../../../video_mask.py) is **already cleanly factored into pure functions**: [`motion_reference`](../../../video_mask.py#L1760), [`window`](../../../video_mask.py#L2247) (including `token_mask`, `drop_specks`, `close_lone_holes`, `drop_islands`, `paint_out`, `soften_subject`), and [`lay_window`](../../../video_mask.py#L976) (`changed_alpha` + `unlaid_frames` cut gate + `lay_back`).
3. **Why Phase 2B cannot wire `|edited - orig|` into `MiniMaxH3MaskedSource` on `fl2va`/`EditGuider` as written:**
   - [`image/2026-11-14_embedded_image_in_video_plan.md`](image/2026-11-14_embedded_image_in_video_plan.md) rightly notes that [`MiniMaxH3GuideLatent`](../../../guide_latent.py#L225-L233) `mask` encodes an RGB control keyframe for paired guide+mask LoRAs rather than attaching a `noise_mask`.
   - However, routing `|edited - orig|` into [`MiniMaxH3MaskedSource`](../../../video_mask.py#L2330) forces the graph onto [`MiniMaxH3AudioFreezeSong`](../../../audio_freeze_song.py#L575-L641) — which has **no `first_frame`, no `last_frame`, no external `GuideLatent` / `ReleaseReferences` hook, and hard-codes `Guider_Basic` ([`audio_freeze_song.py:947`](../../../audio_freeze_song.py#L947)) instead of [`MiniMaxH3EditGuider`](../../../edit_guidance.py)**.
   - In addition, thresholding `|edited - orig|` on a single frame gives a **static 2D region**, whereas any moving subject across a `141`-frame scout pass needs a **`[T, H, W]` tracked mask** (`MiniMaxH3SubjectTrack`) — and two clean non-song ways exist to apply it (`MiniMaxH3EditGuider.mask` softly today/Stage 1, or extracting `video_mask.py`'s single-window functions onto standard `LATENT`/`IMAGE` sockets in Stage 2).

## 3. Leverage Today Over `:8188` API (Zero Changes to `fun`/`fun2` or Existing Nodes)

### 3.1 Two-Phase PCIe-Staged Execution Topology (`24 GB` 4090 + `125.5 GiB` RAM, `0 B` Swap)

Core's `load_models_gpu` evicts the active DiT when `SAM 3.1` or `Sapiens2` execute ([`sapiens2_parts.py`](../../../sapiens2_parts.py)). Weights reload quickly from `125.5 GiB` DDR5 host RAM over PCIe (`Swap = 0 B`), yet alternating perception and `20 GB` DiT sampling inside an inner single-clip loop still pays repeated reloads on every seed or arm.

Because the workflows are **Python-driven via `/prompt` + `client_id`**, batch perception and generation separately:

```text
PASS 1 — Perception Batch (SAM 3.1 + Sapiens2 / SAM 3D Body ViT-H; zero DiT loaded)
  Inputs: generated stills, reference plates, or scout clips
  Stills: LoadImage -> MiniMaxH3SAM31Corrections -> core SAM3_Detect (avoids SubjectTrack head filter)
  Clips : Load -> MiniMaxH3SAM31Corrections -> MiniMaxH3SubjectTrack (any subject_phrase)
               -> MiniMaxH3SubjectParts (parts / matte / held / classes) + MiniMaxH3SubjectBoxes
               -> (optional) MiniMaxH3SAM3DBodyViTHLoader -> MiniMaxH3BodyPose -> MiniMaxH3BodyMeshVideo
  Output: lossless masks (.mkv via MaskToImage+VHS_VideoCombine or PNG) + shot_table + boxes JSON + marked mesh

PASS 2 — Generation / Edit Loop (P-H3-Image LoRA + Pika fl2va/ref2va; 0 disk swap across N arms/seeds)
  Loop  : P-H3-Image (8->4 MP) -> (optional Tier 3 MiniMax-H3-Image 16->4 MP) / heylook align
               -> SpriteTrajectory(mask=...) / GuideLatent(17m) / ReleaseReferences -> EditGuider -> Pika Sampler

PASS 3 (optional, after batch) — Automated Perception QC Gate
  Graph : Run SubjectTrack(subject_phrase=...) + SubjectBoxes on output MP4s
  Checks: unintended hard cuts (shot_table/cuts), subject drop frames, trajectory deviation
```

## 4. Cross-Pillar Compound Unlocks (No Opaque Task LoRAs Needed)

Bringing **high-res `t = 1` stills + SAM 3.1 / Sapiens2 / SAM 3D Body ViT-H perception + `0.33` guide/ref release + `SoundCues` + `SpriteTrajectory` + `EditGuider` + `AudioRefine` + `heylook`** together in Python-orchestrated workflows unlocks high-value capabilities on base/Pika weights alone:

### Unlock A — Directed Multi-Actor Physics & Foley From Any Single Still
- **Pillars:** Tier 1/2/3 Still + `SAM 3.1` (`SAM3_Detect` / `SubjectTrack` + `SubjectParts.held`) + `SpriteTrajectory` (`<Video 1>`) + `SoundCues` (`cond_audio`) + `ReleaseReferences(video_end_percent=0.33, audio_end_percent=0.60)` + `EditGuider(streams="video_only")`.
- **How it beats motion LoRAs:** Instead of baking a narrow motion pattern into an uninspected external LoRA, you get **exact 2D trajectory (`(x, y, face, scale, hop)`), exact prop preservation (`held` mask attached to subject cutout), and exact `3`-frame (`125 ms`) impact timing (`SoundCues` with `-28 dBFS` rumble floor)** simultaneously—releasing rigid cutouts at step `2` (`0.33`) so base H3/Pika synthesizes natural stride physics and keeping `streams="video_only"` so organic room tone and foley emerge cleanly (`r = -0.0812` `.wav` bleed).
- **Ready extension already queued:** 2-subject chained `<Video 1>` + `<Video 2>` trajectories ([`docs/wiki/next_steps.md`](../next_steps.md), Atlas Item `#3`), later aided by `gem/perception-lhf`'s `arbitrate_multiplex_masks` once gated.

### Unlock B — Soft Regional Evolution (`Scout -> SAM 3.1 Moving Mask -> Parked EditGuider.mask + Released 17m Guide`)
- **Pillars:** `Pika` Scout + `SAM 3.1` `[T, H, W]` `MASK` + `P-H3-Image` `8->4 MP` (or Tier 3 `MiniMax-H3-Image`) + `MiniMaxH3GuideLatent(17m, guide_end_percent=0.33..0.50)` + `heylook` aligned `MIDCLIP_GUIDE_PROMPT` + Parked **Path B `MiniMaxH3EditGuider.mask`** ([`docs/wiki/next_steps.md`](../next_steps.md)).
- **Why this cleanly solves Phase 2A + Phase 2B without touching `AudioFreezeSong`:**
  1. Run a 6-step Pika scout clip (`141` frames, `on_both_clocks`).
  2. Edit frame `17m` (`f68`) via `P-H3-Image` (relight, creature/wardrobe metamorphosis, prop arrival), optionally keeping clean outside pixels via dilated `|edited - orig|` (`CHANGE_THRESHOLD = 0.05`).
  3. Run `MiniMaxH3SubjectTrack` on the **scout video** to obtain a frame-accurate moving `[T, H, W]` mask of the target region (`subject`, `held`, or inverted background).
  4. Apply [`EditGuider`](../../../edit_guidance.py) (`v0 + (v1 - v0) * (eff_v * mask_packed)` on `packed_split`, pooled identically over `[1, 4, 4, 4, 4]` + `video_mask.fit_mask` so `T == 1` broadcasts cleanly and moving limbs aren't eroded) alongside `GuideLatent(17m)` + `guide_end_percent = 0.33..0.50`. Note: when `mask` is active (`self.mask is not None`), steps `> last_step` still need 2 DiT passes unless masked steering stops too (`next_steps.md`), and `streams="video_only"` keeps 2 passes past `last_step` (`edit_guidance.py:234-253`).
- **Payoff vs. hard `noise_mask`:** Preserves original environment motion and allows ambient lighting interaction across the mask boundary without hard `lay_window` seams—at 6-step Pika speed. Open scientific test noted in [`docs/wiki/next_steps.md`](../next_steps.md): measure attention cross-talk outside `mask` on early steps (e.g., blizzard edit with foreground subject masked out).

### Unlock C — Fast Distilled Video + Pixel-Locked Undistilled Cinematic Audio Pass
- **Pillars:** `Pika` 6-step Video (`or SAM-masked video pass`) + `MiniMaxH3AudioRefineMask(video_mask=0.0, audio_mask=1.0)` ([`audio_refine.py:32-69`](../../../audio_refine.py#L32-L69)) + `MiniMaxH3FrozenVideoCache` ([`frozen_video_cache.py:914`](../../../frozen_video_cache.py#L914)) + `MiniMaxH3SoundCues` + pre-distill Base H3 model.
- **Why this avoids the retired trap:** [`2026-10-06_frozen_cache_masked_window.md`](../../../bench/results/2026-10-06_frozen_cache_masked_window.md) proved `MiniMaxH3FrozenVideoCache` loses to Sol-Attn when `23%+` of video tokens are live (`463.8 s` vs `462.9 s`). **When `video_mask = 0.0` (`AudioRefine`), only audio + text tokens are live**, so cached base-model refinement keeps every single generated video pixel bit-identical while recovering undistilled acoustic richness (foley textures, rain ambience, vocal timber) guided by aligned `overall_soundscape` / `SoundCues`!

### Unlock D — Scriptable Narrative Beat Sheets (`Phase 1` + `EncodeReferences` Split KV + Counterfactual A/B)
- **Pillars:** Tier 2/3 Still + `MiniMaxH3EncodeReferences` ([`reference_encode.py:468`](../../../reference_encode.py#L468)) / `MiniMaxH3PromptOnReferences` ([`reference_encode.py:541`](../../../reference_encode.py#L541)) + `MiniMaxH3GuideLatent(17m)` + `guide_end_percent = 0.33..0.50` + programmatic `heylook` prompt beat alignment.

## 5. Clean Future Extraction: Decoupling Hard `MaskedSource` Off `AudioFreezeSong`

When you want **hard pixel-locked `noise_mask` video-to-video** directly inside single-window Pika / `EditGuider` / `GuideLatent` / `SamplerCustomAdvanced` pipelines **without waiting for `'fun2'` or altering [`MiniMaxH3AudioFreezeSong`](../../../audio_freeze_song.py)**, keep [`MiniMaxH3MaskedSource`](../../../video_mask.py#L2330) as the sole widget/validation front-end (`33` inputs including `replace`, `parts`, `keep`, `others`, `edge`, `paint_out`, `render_region`, `encode_frames`, `motion_reference`), and wrap its runtime calls via **two thin single-window adapter nodes** carrying a zoomed window state handle (`H3MaskedWindow`):

──────────────────          ───────────────────────────────           ────────────────────────
MiniMaxH3MaskedSource ────► MiniMaxH3MaskedApply

   zero duplicated widgets)   1. video_mask.zoomed_source(src,w,h)    │                     ReleaseReferences (0.33)
                              2. window_references(...) (if motion)   ├─► LATENT (NestedTensor + video noise_mask)
                              3. video_mask.window() + vae.encode()   │     ├─► optional MiniMaxH3FreezeAudio (freeze track)
                                 + start_zero_tokens() + sigmas[late:]│     └─► omit FreezeAudio -> fresh synced foley!
                              outputs: LATENT, H3_REFERENCES,         │   ─► EditGuider -> SamplerCustomAdvanced

                                                                      ▼

### Why Combining `zoomed_source` + `H3MaskedSource` Prevents Subtle Failures
- **Fixes the `RENDER_ZOOM` / `MaskedMotionRef` race:** In [`audio_freeze_song.py:721 -> 836 -> 880 -> 989`](../../../audio_freeze_song.py#L721), `video_mask.zoomed_source(source, width, height)` **must run before both** `window_references` (`motion_reference`) and `video_mask.window`, while stashing `source["whole"]` + `zoom` for `lay_back`. Splitting `motion_reference` into an unlinked node reading un-zoomed `H3MaskedSource` would hand full-frame `<Video N>` refs to a zoomed render; bundling `zoomed_source -> window_references -> window` inside `MiniMaxH3MaskedApply` guarantees crop-render-layback parity automatically.
- **Native optional-audio choice:** Passing `MiniMaxH3MaskedApply`'s `LATENT` (`NestedTensor` video mask, all-ones audio mask) through [`MiniMaxH3FreezeAudio`](../../../audio_freeze.py#L234-L260) locks the original soundtrack (`L341` preserves `parts[0]`); **omitting** `MiniMaxH3FreezeAudio` locks untouched video pixels while generating brand-new synchronized foley inside the same pass—something [`audio_freeze_song.py:819`](../../../audio_freeze_song.py#L819) cannot do today.
- **Required invariants on `MiniMaxH3MaskedApply`:** Enforce `h3_rules.on_both_clocks` (`39 + 51m`: `39, 90, 141, 192, 243, 294, 345`), match `audio_freeze_song.py:940-945` when `not bool(src_tokens.any())` (`untouched`: zero live mask tokens—either bypass in API orchestration or carry `untouched` inside `H3MaskedWindow` so `MaskedComposite` returns `src_pixels` / zero matte), and never duplicate `MiniMaxH3MaskedSource` inputs.
