# Edit guidance: steer a render with an edited copy of its prompt

last updated: 2026-11-09

You change a few words of your own prompt and turn a scale. No control vector is built or loaded. Each
sampling step the model is run on the prompt as written and on the edited prompt, and the result is moved
from the first toward the second by the scale.

The owner passed the hand-wired form of this on 2026-11-09 ([`decisions.md`](decisions.md)). How it compares
with a control vector, and what has and has not been measured, is in
[`../research/control_vectors/2026-11-09_control_vector_simplification_plan.md`](../research/control_vectors/2026-11-09_control_vector_simplification_plan.md),
sections 21 and 25.

## The two nodes

Both are in `edit_guidance.py`. Their inputs, defaults and tooltips are the node's own `define_schema`; the
defaults and their reasons are `h3_rules.EDIT_GUIDANCE_DEFAULTS`.

- **MiniMax H3 Prompt Edit** takes the prompt and one edit a line, `old wording -> new wording`, and gives
  the edited prompt. The old wording must occur exactly once. A line that starts `soundscape:` edits the
  soundscape section. It refuses, in its own words, a line with no arrow, wording that is absent or repeated,
  wording inside dialogue, and wording that carries a tag or a header.
- **MiniMax H3 Edit Guider** goes where `BasicGuider` goes. It takes the model and two conditionings, the
  original and the edited, made with the same encoder, references and canvas. At scale 0 it is the original
  prompt, at 1 the edited prompt, above 1 it pushes past the edit. `first_step` runs the original alone
  before that step, which keeps its framing.

## The graphs

Generated by `workflows/build_workflows.py` (`edit_guidance=` on a graph's row); the edit lines are data in
`prompt_bank/edit_guidance/`.

- `workflows/h3_text_to_video_pika_edit_guidance_api.json`: text to video. Two conditioning nodes, one per
  prompt.
- `workflows/h3_image_ref_plus_text_to_video_pika_edit_guidance_api.json`: with a reference picture. The
  reference is encoded once (`MiniMaxH3EncodeReferences`) and each prompt goes on top of it
  (`MiniMaxH3PromptOnReferences`).

In both, the prompt is written once, on a text node (core's `PrimitiveStringMultiline`) that feeds the
first conditioning node and the edit node. Change it there and both follow.

## What to know

- It costs a second model pass on every step the edit is on.
- An edit changes whatever its words change. An edit inside `subject_definitions:` or
  `retention_analysis:` changes who the subject is, not the look.
- The scale's useful range is the owner's look of 2026-11-09: the default is a little stronger than the
  edited prompt alone, and well above it the picture gains color the edit did not ask for.
- A test tool, `bench/edit_guidance_arms.py`, builds comparison arms from a shipped graph (the prompt alone,
  the edited prompt alone, edit guidance, a control vector) and can queue them.
- Its check is `bench/check_edit_guidance.py`: the refusals and the guider's arithmetic, with no model.
