- **Corrected `flip_null` definition, `apply_to_null` polarity semantics, and `grade` attention default in [`docs/wiki/research/control_vectors/2026-11-04_h3_control_vectors.md`](../research/control_vectors/2026-11-04_h3_control_vectors.md)**:
  1. §4.3's formula and inline note used to define `flip_null` as `context_pos -> context_pos + s * v, context_neg -> context_neg - s * v (effective CFG delta (1 + 2 * cfg) * s * v)`. That contradicted §4.3's prose two lines above ("Applying `+s * v` to the positive branch and `-s * v` to the null branch ... leaves the conditioned branch intact and pushes the unconditioned branch away from the target concept") and `control_vector_nodes.py` (`MiniMaxH3ControlVector` applies `-s * v` to `negative` only when `apply_to_null == "flip_null"`), because shifting both branches gives `(1 + cfg) * c_pos - cfg * c_neg + (1 + 2 * cfg) * s * v` rather than leaving the positive branch intact. Updated the formula in §4.3 to `context_pos -> context_pos, context_neg -> context_neg - s * v (effective CFG delta cfg * s * v)`.
  2. §4.3 (`apply_to_null`) and §8.1 (`MiniMaxH3ControlVector`) used to describe `"both"` as adding `+s * v` to both `positive` and `negative` (`c_neg + (1 + cfg) * (c_pos - c_neg) + s * v`, a constant `1 * s * v` offset independent of `cfg`). `control_vector_nodes.py` implements `"both"` as opposite-sign push-pull (`+s * v` on `positive`, `-s * v` on `negative`, giving `(1 + 2 * cfg) * s * v`) so `"both"` amplifies CFG separation rather than cancelling the `cfg`-scaled term. Updated §4.3 and §8.1 with a dated inline note so the paper and node match.
  3. §3.1 used to say that the Step-0 velocity probe runs with `MiniMaxH3Sol` enabled on non-exempt graphs so `grade` matches the default render path. `bench/control_vectors.py::cmd_grade` defaults to stock dense attention (with `--sol` opt-in) so the Step-0 velocity delta is not confounded by dynamic block-sparse routing changes between baseline and steered passes (`bench/measure_marker_epsilon.py` precedent). Updated §3.1 with a dated inline note.
