# docs/masked_v2v/: the masked video-to-video lane

Loaded when a session opens a file here; `docs/AGENTS.md` and the root `AGENTS.md` still govern.

- **`index.md` lists every page here.** Read it first; a new page gets a row.
- **The lane's rules are `data/AGENTS.md`**, and each video's state is its own `data/<video>/AGENTS.md`. These pages
  say how the lane works and what is known; they hold no video's state.
- **This lane is one use of H3.** A finding about common code (reference conditioning, the shared nodes) is written
  where that code's page is, under `docs/h3/`, and linked from here.
