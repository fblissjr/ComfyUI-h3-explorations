# docs/working/: running the box, and working with the owner

Loaded when a session opens a file here; `docs/AGENTS.md` and the root `AGENTS.md` still govern.

- **`index.md` lists every page here.** Read it first; a new page gets a row.
- **`working_with_the_owner.md` is read by every session of either model before it speaks to the owner.**
- **`runbook.md` is pointers only**: a step's detail lives in the tool or page it names, never copied here.
- **`hardware.md` carries no values**; `bench/hwinfo.py` prints them.
