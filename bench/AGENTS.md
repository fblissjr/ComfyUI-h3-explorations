# bench/: the tools, the checks and the records

Loaded when a session opens a file here; the root `AGENTS.md` still governs.

- **Find a tool in `INDEX.md` here before writing one.** It lists every tracked script by what it says it does,
  generated by `bench/build_index.py` (never edited by hand; `--check` says whether it is current).
- **A tool worth keeping is tracked with a check**, and the check has its row in `docs/method/checks.md` (the standard and
  the index of what each check defends). `bench/check_doc_inventory.py` fails on a check with no row.
- **Lane tools and common tools live side by side here.** Before changing a tool, see who calls it: a masked-lane
  change does not narrow a tool another use runs (root `AGENTS.md`, "The repo is broader than the current project").
- **A record under `results/` is its `.md`** (`results/INDEX.md`); data goes under the untracked `data/<video>/`.
- **Run with the ComfyUI venv's python, never `uv`** (`docs/working/comfy_notes.md`, "Running things").
- **While the card runs, a tool a load step calls is edited in a worktree**, never in the shared tree (root
  `AGENTS.md`, "The shared tree").
