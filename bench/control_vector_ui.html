Separate Experimental Tool About J-Lens (24,912-Word Unigram Atlas)

How J-Lens differs from Full Prompt-Pair Control Vectors: J-Lens is a pre-computed 24,912-word single-token Jacobian dictionary (j_lens.py). It runs on CPU in < 2 ms with zero GPU pass, making it useful for diagnostic lexical readouts (seeing which single words align with a vector) and fast word-bag prototypes. Because single words lack multi-clause context and [00s-05s] timeline structure, use Screen 2 or Screen 3 when building production cinematic vectors.
