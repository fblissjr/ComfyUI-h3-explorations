## Why

The core update of this morning moved the pin to `comfy-kitchen==0.2.35`, and
its requirements install replaced `0.2.34+sol.36e29f1` with the stock wheel.
The stock wheel has none of what this pack's default graphs ask of Sol
(`qk_balance`, `rotate`, `blk_cnt`), so the Sol node refused every default
video graph at patch time. Found when the first render of the day failed.
