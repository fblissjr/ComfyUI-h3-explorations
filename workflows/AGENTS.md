# workflows/: the shipped graphs and the shared constants

Loaded when a session opens a file here; the root `AGENTS.md` still governs.

- **Never hand-edit a graph (`*.json`).** `build_workflows.py` writes them; nothing is true of a graph until it is
  rebuilt. `INDEX.md` here lists each graph's chain, generated by `bench/build_index.py`.
- **`h3_config.py` holds every shared constant, one copy each**, with its provenance beside it (measured, inherited
  or reasoned). `h3_rules.py` (at the repo root) holds what the model allows.
- **Every walker goes through `h3_config.graph_paths`.**
- **A default here serves every use of the pack.** A change made for the masked lane goes behind the lane's own input
  or plan data unless it is right for every graph (root `AGENTS.md`, "The repo is broader than the current project";
  "A tinkering repo" for adopting upstream defaults).
